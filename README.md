# Molokog – Prototipo de interfaz (IHC, Práctica 3)

Prototipo funcional de una tienda de ropa urbana, diseñado con el proceso de Diseño Centrado en el Usuario (ISO 9241-210) y evaluado con las heurísticas de Nielsen y WCAG 2.2 AA.

## Demo
URL desplegada: _ https://eduardomartinez5955-hash.github.io/Molokog/_

## Funciones
- Catálogo con filtro por categoría
- Detalle de producto con selección de talla
- Carrito con cantidades y total
- Pago con validación en tiempo real y confirmación

## Tecnologías
HTML5, CSS3 y JavaScript sin frameworks, en un solo archivo (`index.html`).

## Accesibilidad
Navegación completa con Tab, Enter y Esc; foco visible; etiquetas asociadas; mensajes de error con aria-live; contraste mínimo 4.5:1; modo oscuro.
